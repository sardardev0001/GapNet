# Repository visibility and licensing

Uploading a project to GitHub does not automatically make it open source.

## Choose visibility

- **Private** (recommended until you complete deployment/security tests): only selected collaborators can view the code.
- **Public**: anyone can view and copy the files, but usage permissions are still governed by your license.

## Choose a license explicitly

No license is bundled automatically. The repository owner should decide whether to add an MIT, Apache-2.0, GPLv3, or other license, and confirm third-party license obligations first.

To add a license, use GitHub's **Add file → Create new file → Choose a license template**, or add a `LICENSE` file locally. Without a license, default copyright rules generally apply, and this repo should not be advertised as open source.
